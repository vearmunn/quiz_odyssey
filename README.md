# Quiz Odyssey

Quiz Odyssey is a quiz application designed for users who want to challenge their knowledge and explore a wide range of topics. The application offers multiple categories and difficulty levels, allowing users to customize their quiz experience and compete through a global leaderboard.

## Features

* 📚 **Extensive Categories** — Choose from a variety of quiz categories, including history, science, arts, entertainment, and more.
* 🎯 **Multiple Difficulties** — Select from three difficulty levels: Easy, Medium, and Hard.
* 🏆 **Global Leaderboard** — Compete with other users and track your performance through a global leaderboard.
* 🔐 **Firebase Authentication** — User authentication is handled through Firebase.
* 💾 **Firebase Storage** — Firebase is used to store application data.
* 🌐 **Open Trivia DB** — Quiz questions are fetched from the Open Trivia DB API.

## Tech Stack

* **Flutter**
* **Dart**
* **GetX** — State management
* **Firebase** — Authentication and data storage
* **Open Trivia DB API** — Quiz question source

## Overview

The goal of Quiz Odyssey was to build an interactive quiz application while practicing state management, API integration, authentication, and data persistence in Flutter.

Users can select a category and difficulty level before starting a quiz. Their performance can then be compared with other users through the global leaderboard.
